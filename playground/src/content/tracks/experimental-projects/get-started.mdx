# Getting started

**You need:** Node 24.x, npm, an editor and a browser for this optional starter. The shared playground uses React.

Follow the root [gallery setup](#/guide/setup) and create a [contribution branch](#/guide/contributing) before editing.

## Make it yours

In another terminal at the repository root, run:

```sh
npm run demo:new
```

Give your demo a name and choose **Experimental Projects**. Open its printed route on your local server and edit `playground/src/demos/<your-id>/Demo.tsx`. The [demo guide](#/create) explains the contract if you need it.

**First result:** change “An idea, taking shape” to your own heading and save. Then try one playable interaction, a quiz question, a drawing or a useful button. It does not need to resemble our example. Inputs reset on refresh; save code and record discoveries you want to keep.

**Success check:** open your demo from the gallery and try your interaction. Refresh and try again: the code change remains, while temporary input may reset. Ask a peer to try it using one sentence of instructions.

**Want a destination?** Open `/#/demo/art` separately for the generative postcard. Read the [worked example](#/track/experimental-projects/examples) only when you want a reference or hint. No generator or export implementation is hidden in your starter.

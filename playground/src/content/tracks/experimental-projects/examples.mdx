# Experimental Projects worked example · A generative postcard

**Experience:** In the running playground, open `/#/demo/art`. Change the dot count, remix the composition, then save an SVG. The same seed produces the same arrangement; the exported file can be opened in a browser independently.

**How it works:** `demos/art/art.ts` produces repeatable points from a seed. `demos/art/index.tsx` draws them with SVG, adds controls and serialises the picture for download. This is a completed reference, separate from your [creative starter](#/track/experimental-projects).

## Build towards it, or branch

1. Draw one shape in your starter.
2. Generate a few shapes from a rule you choose.
3. Add one control that changes the result.
4. If useful, add reproducibility or saving; neither is necessary for a first discovery.

Try a spiral, a title, data-driven sizes or a tiny game. Borrow the generator when you want to focus on interaction instead of rebuilding every piece.

For another direction, explore the [D3 idea atlas](#/track/modern-web/examples) or use local signals to control a palette from a second tab. Local tabs are not multi-device networking.

**Small checks:** logic tests cover repeatability and bounds. Try remixing and SVG download yourself when changing those interactions. Those checks do not decide whether your visual idea is interesting. Show a result and one thing you learned; an unfinished prototype counts.

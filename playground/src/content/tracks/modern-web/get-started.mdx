# Getting started

Try a browser capability, then make one visible change in your own React demo.

## 1. Run the Lab locally

Follow [Local setup](#/guide/setup), then choose **Modern Web Capabilities** in the gallery.

## 2. Try the starter

Move the radius control in this circle starter. The circle and displayed radius should change. This is a small preview, separate from the finished examples.

<DemoBoundary>
  <section className="experiment">
    <BrowserStarter />
  </section>
</DemoBoundary>

## 3. Create your own demo

On your own [contribution branch](#/guide/contributing), open another terminal at the repository root:

```sh
npm run demo:new
```

Choose **Modern Web Capabilities**, then open your new demo from the gallery. Edit `demos/<your-id>/index.tsx`; [Create a demo](#/create) covers the generator and package structure.

## 4. Make something happen

**First result:** change the circle fill colour in your generated `index.tsx` and save. Open your demo and move the radius control.

**Success check:** refresh: the saved colour remains while the radius resets. Navigate away and back; it should still work without console errors. Then add another shape or try your own interaction.

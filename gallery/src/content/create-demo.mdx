Choose a suggested idea, remix a demo or bring your own question. Keep the first experiment small enough to explain what you tried and learned.

If you are adapting an existing demo, follow [local setup](#/guide/setup) and edit its folder under `demos/`. A guide investigation can start in your own project; you do not need to generate an app for it.

### Start a new demo

From the repository root, after [local setup](#/guide/setup):

```sh
npm run demo:new
```

Choose a name, folder ID and track; add your name and a short description. These are editable later. Replace `your-id` below with your folder ID:

```sh
npm install
npm run dev --workspace @lab/demo-your-id
```

Open the URL printed by Vite.

Or run `npm run dev` to open the gallery; your demo appears automatically.

### Make it yours

Edit **`demos/<your-id>/index.tsx`**; saving updates the browser. Modern Web starts with a circle; other tracks use an idea card. Change or replace either.

Your code, assets and notes belong in that folder. Change `demo.config.ts` to update the gallery title or description.

<details>
<summary>Check your demo</summary>

Replace `your-id` with the folder ID you chose:

```sh
npm run check --workspace @lab/demo-your-id
```

This checks types and builds to `demos/<your-id>/dist/`, independently of the gallery. Run `typecheck` or `build` separately for faster feedback.

</details>

Optional `requirements` in `demo.config.ts` (`internet`, `secure-context`) appear in the gallery before people open the demo.

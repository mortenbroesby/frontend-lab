To remix a demo, follow [local setup](#/guide/setup) and edit its folder under `demos/`. Use the generator below only when you want a new app.

### Start a new demo

From the repository root, after [local setup](#/guide/setup):

```sh
npm run demo:new
```

Enter a demo name. The generator creates its folder ID automatically: **My First Demo** becomes `my-first-demo`. Use the commands it prints, or replace `your-id` below with that ID:

```sh
npm install
npm run dev --workspace @lab/demo-your-id
```

Open the URL printed by Vite.

Your demo also appears in the gallery (`npm run dev`).

### Make it yours

Edit **`demos/<your-id>/index.tsx`**; saving updates the browser. The starter contains a small idea card. Change or replace it.

Your code, assets and notes belong in that folder. New demos appear under Experimental Projects. Edit `demo.config.ts` whenever you want to change the tracks, description or author. Add multiple IDs to `tracks` to list a demo in more than one track; the first is its default when opened directly.

<details>
<summary>Check your demo</summary>

Replace `your-id` with the generated folder ID:

```sh
npm run check --workspace @lab/demo-your-id
```

This checks types and builds to `demos/<your-id>/dist/`, independently of the gallery. Run `typecheck` or `build` separately for faster feedback.

</details>

Optional `requirements` in `demo.config.ts` (`internet`, `secure-context`) appear in the gallery before people open the demo.

# Create a demo

From the repository root, after [local setup](#/guide/setup):

```sh
npm run demo:new
```

Give it a name, accept or edit the suggested folder ID, and choose a track. Add your name and a short description; you can change these later. Then, from the repository root (replace `your-id` with your folder ID):

```sh
npm install
npm run dev --workspace @lab/demo-your-id
```

Run `npm install` once after generation to link the new workspace. Open the URL printed by Vite.

Prefer the gallery? Run `npm run dev` instead and open your demo there. It appears automatically—no registration needed.

## Make it yours

Edit **`demos/<your-id>/index.tsx`** and save; the browser updates automatically. Modern Web starts with a circle; the other tracks start with an idea card. Keep, change or replace the starter.

Your code, assets and notes belong in that folder. Change `demo.config.ts` to update the gallery title or description.

<details>
<summary>Check your demo</summary>

Replace `your-id` with the folder ID you chose:

```sh
npm run check --workspace @lab/demo-your-id
```

This checks your demo’s types and builds it. Use `typecheck` or `build` separately for a shorter feedback loop. The build goes into `demos/<your-id>/dist/` and runs independently of the gallery.

</details>

Optional `requirements` in `demo.config.ts` can contain `offline`, `internet` or `secure-context`. These appear in the gallery so people know what they need before opening the demo.

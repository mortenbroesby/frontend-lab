# Your first experiment

After [local setup](#/guide/setup), open [Device Rally](#/demo/device-rally) in two browsers using the same room code. Send a cheer, then find the cheer interaction in `demos/device-rally/index.tsx`. Change its presentation before adding a new message.

Device Rally uses WebRTC and public signaling through Trystero. It requires internet access and localhost or trusted HTTPS. Plain LAN HTTP on your phone is not supported. Physical phones and the workshop network still need verification. [Connection details and alternatives](#/track/modern-web/devices).

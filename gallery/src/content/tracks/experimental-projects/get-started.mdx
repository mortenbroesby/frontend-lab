# Getting started

**You need:** Node 24.x, npm, an editor and a browser for this optional starter. The shared gallery uses React.

Follow the root [gallery setup](#/guide/setup).

## Make it yours

In another terminal at the repository root, run:

```sh
npm run demo:new
```

Give your demo a name and choose **Experimental Projects**. Open its printed route on your local server and edit `demos/<your-id>/index.tsx`. The [demo guide](#/create) explains the contract if you need it.

Start with one interaction: a creature following food, a shape making a sound or a button triggering a chain reaction. Your generated starter is independent of the completed demos.

The **Demos** tab has a pond and a generative postcard to inspect when you want a reference.

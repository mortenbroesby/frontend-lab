# Getting started

**You need:** Node 24, npm, an editor and browser. This optional starter uses React.

Follow the root [gallery setup](#/guide/setup).

## Make it yours

In another terminal at the repository root, run:

```sh
npm run demo:new
```

Name your demo and choose **Experimental Projects**. Open its local route and edit `demos/<your-id>/index.tsx`; see the [demo guide](#/create).

Start with a creature following food, a sounding shape or a chain-reaction button. Generated starters are independent of completed demos.

Find pond and generative postcard references in **Demos**.

## Make change easy to follow

A card moves to another position. A thumbnail opens into a detail view. Half a collection disappears after filtering. Can you keep track of what happened without reading an explanation?

Try <DemoLink id="motion-with-purpose">Motion with purpose</DemoLink>: an interactive collection of six graphic prints. Filter it, mix up the order and open a print. Then turn motion off and compare the same actions.

### Keep an object recognisable

Start with a grid of things you care about: album covers, photos, recipes or project cards. Change their order while keeping stable React keys. Can your eye follow an item to its new position?

Explore [Motion layout animations](https://motion.dev/docs/react-layout-animations). Let CSS determine the final layout; use motion to connect the old and new positions. Try a different column count or spacing before adding more effects.

### Connect a thumbnail to its detail

Open one item into a larger view. What should remain recognisable: its artwork, title, colour or position?

Investigate shared elements with `layoutId` in the [layout guide](https://motion.dev/docs/react-layout-animations). The reference uses a shared artwork identity and a dialog from the Lab UI library. The dialog handles focus, Escape and keyboard access; the animation only explains the visual connection. Explore a different transition without replacing those behaviours.

### Make room when items leave

Add a category filter. Try removing items instantly, then letting them leave before or while their neighbours move. Which feels clearer when you change filters quickly?

Read [AnimatePresence](https://motion.dev/docs/react-animate-presence), including `mode="popLayout"`. Compare opacity and scale, then experiment with [duration and easing](https://motion.dev/docs/react-transitions). Change one parameter at a time so you can tell what made the difference.

### Start your own experiment

After [local setup](#/guide/setup), run the reference:

```sh
npm run dev --workspace @lab/demo-motion-with-purpose
```

`demos/motion-with-purpose/posters.tsx` contains the original SVG artwork and collection data. `index.tsx` connects filtering, ordering and the detail view. Replace the subject, change a transition or build your own collection through [Create a demo](#/create).

CSS transitions are enough for simple colour and opacity changes. Motion is useful here because elements enter, leave and change layout. An authored illustration is a different problem; this example doesn't need a separate animation player.

### Keep it usable without movement

Try the keyboard, close a detail view with Escape, and change filters mid-transition. Enable your device's Reduce Motion setting. Are the same actions and results still available, and does focus return to the print you opened?

Use [Motion's accessibility guidance](https://motion.dev/docs/react-accessibility). Animation should explain a state change, not delay it or become a requirement for understanding it.

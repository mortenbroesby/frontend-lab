<section className="quality-method" aria-labelledby="method-heading">
<h2 id="method-heading">How to work on it</h2>
<ol>
<li><strong>Start with something specific.</strong><p>One package, function, test or connection is enough. Decide what you want to understand or improve.</p></li>
<li><strong>Understand it before editing.</strong><p>Follow its callers, run the relevant check and establish what must keep working.</p></li>
<li><strong>Try a change and compare.</strong><p>Did it answer your question or make the code easier to work with? Keep it if it helps. Leaving the code as it is can be the right result.</p></li>
</ol>
</section>

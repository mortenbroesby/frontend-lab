# What would make development easier?

**Identify friction → Explore alternatives → Experiment → Demonstrate results.**

Pick something that interrupts your actual work. Finding an existing solution is just as useful as building a tool. Work in this Lab or a repository you already know.

## Show the difference

Demonstrate the original friction, the alternative you tried and one observable result: a test rerun, a clearer error, fewer steps or a useful review finding. Mention one limitation. No report or polished tool required.

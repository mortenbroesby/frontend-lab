# Ideas to explore

Identify friction → Explore alternatives → Experiment → Demonstrate results.

Use this repository or your own to address real friction. Finding an existing solution is as useful as building one.

## Faster Feedback Loops

Explore targeted tests, watch modes, caching and affected-project detection. How quickly can you get useful evidence about your change?

Compare a test file with one named test; watch it respond to edits. Inspect selected monorepo tasks before running them. Explain a cache miss or find fewer checks that catch the regression; broader checks may still be needed.

Read: [Node test filtering and watch mode](https://nodejs.org/docs/latest-v24.x/api/test.html) and [Turborepo’s task-selection and dry-run options](https://turborepo.dev/docs/reference/run).

## Developer Tools

Find or build a CLI, Git utility, debugger aid or automation that answers an awkward question.

Compare `npm run`, `git diff --stat` and `git diff --check` with a custom report. Replace recurring console logs with a debugger feature. New utilities should start read-only and handle one real edge case before expanding.

Read: [Git diff options](https://git-scm.com/docs/git-diff) and [Node’s native argument parser](https://nodejs.org/docs/latest-v24.x/api/util.html#utilparseargsconfig).

### Idea: a Sapphire usage inspector

Explore a Sapphire React usage inspector that locates potential issues and explains what to investigate.

Candidates include deprecated components/props, missing setup, composition and accessibility guidance. These are not confirmed Sapphire rules.

Define a useful finding. When Sapphire docs, types or examples are available, choose one documented rule. Could lint, source analysis or browser inspection check it? Show evidence and a next step without claiming overall correctness.

Idea only: Sapphire’s package, repository and docs are unavailable; no integration or checks exist.

## Development Workflows

Explore API mocking, monorepo tools, environments or builds to escape slow services, unclear setup or broad commands.

Compare request blocking, throttling or response overrides with a fetch stub for loading/error states. Compare standalone and filtered monorepo builds, or have a peer try your minimal environment.

Read: [Chrome DevTools local overrides](https://developer.chrome.com/docs/devtools/overrides) and [Turborepo run reference](https://turborepo.dev/docs/reference/run).

## Agentic Workflows

Explore Codex/Copilot skills, bounded tasks and automated reviews with an existing agent, or rehearse manually.

Compare a prompt with a skill specifying task, boundaries, checks and evidence. Review one change without edits; compare findings with your inspection and checks. What becomes repeatable, and where is judgement needed?

Read: [Codex skills](https://developers.openai.com/codex/skills) and [Copilot CLI skills](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-skills).

Show fewer steps, clearer feedback or a reason to keep your approach, plus one limitation. No polished tool or report needed.

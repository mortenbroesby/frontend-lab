# Getting started

Try a browser capability in your own React demo.

[Connect two browsers](#/track/modern-web/devices), or start with the circle below.

## 1. Run the Lab locally

Follow [Local setup](#/guide/setup), then choose **Modern Web Capabilities** in the gallery.

## 2. Try the starter

Move the radius control; the circle and value should change. This starter is separate from finished examples.

<DemoBoundary>
  <section className="experiment">
    <BrowserStarter />
  </section>
</DemoBoundary>

## 3. Create your own demo

Open another terminal at the repository root:

```sh
npm run demo:new
```

Choose **Modern Web Capabilities** and open your demo in the gallery. [Create a demo](#/create) explains generation and package structure.

## Pick your first interaction

Edit `demos/<your-id>/index.tsx`: add pointer interaction, message a Worker or try an unfamiliar API. Aim for one visible result.

**Demos** contains independent references. Already have a React project? Use its setup.

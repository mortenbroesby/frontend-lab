# Getting started

Try a browser capability, then make one visible change in your own React demo.

Want to connect two browsers first? [Try Devices talking to each other](#/track/modern-web/devices). Prefer a minimal visual starter? Continue below.

## 1. Run the Lab locally

Follow [Local setup](#/guide/setup), then choose **Modern Web Capabilities** in the gallery.

## 2. Try the starter

Move the radius control in this circle starter. The circle and displayed radius should change. This is a small preview, separate from the finished examples.

<DemoBoundary>
  <section className="experiment">
    <BrowserStarter />
  </section>
</DemoBoundary>

## 3. Create your own demo

Open another terminal at the repository root:

```sh
npm run demo:new
```

Choose **Modern Web Capabilities**, then open your new demo from the gallery. Edit `demos/<your-id>/index.tsx`; [Create a demo](#/create) covers the generator and package structure.

## Pick your first interaction

Edit `demos/<your-id>/index.tsx`. Add pointer interaction, send a message to a Worker, or try a browser API you have never used. Start with one visible result.

The **Demos** tab has working references; your generated starter does not import their implementations. Already have a React project? Use its usual setup.

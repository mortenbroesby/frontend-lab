## Explore further

| Starting point | First observation | Optional stretch |
| --- | --- | --- |
| Visual interaction | Change one SVG shape with a control or pointer. | Add a few D3 nodes and one force, or compare SVG with Canvas. |
| Responsive computation | Send a small value to a Worker and render its reply. | Add progress or cancellation; compare interaction responsiveness under a bounded workload. |
| Local real-time messages | Open Signals between tabs in two same-origin tabs and send a message. | Share a palette or quiz event without a feedback loop. |
| Cross-device messages | Open [Device Rally](#/demo/device-rally) in two browsers using the same room code. | Send cheers, leave and rejoin, or invent a shared interaction. |

**Communication boundary:** Signals uses BroadcastChannel within one browser context. Device Rally uses Trystero public signaling and WebRTC between peers; it needs internet access and localhost or trusted HTTPS. No custom server is required. Physical phones and the workshop network remain untested.

[Worked references](#/track/modern-web/examples) cover D3, SVG, Workers and tab messages. Start with one small piece; the completed examples are separate from your bootstrap.

You need repository access, **Node 24**, **npm 11.6.2** and an editor.

Clone the repository, then run from its root:

```sh
npm ci
npm run dev
```

Open the URL printed in the terminal. Keep the server running while you work.

[Choose a track](#/) or [create a demo](#/create).

On Windows, use PowerShell or Command Prompt; WSL is not required. If PowerShell
blocks `npm.ps1`, replace `npm` with `npm.cmd` in these commands. This avoids
changing your execution policy.

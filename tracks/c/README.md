# Track C · Developer Experience & Tooling

Choose recurring workflow friction and explore a practical improvement. The outcome can be a discovered feature, simpler command or small script.

1. **[Start small: script and test bootstrap](bootstrap.md)** — a read-only Node script that identifies a project, with a small test.
2. **[Try the worked command inventory](examples.md)** — see how a concrete onboarding question became a small local report, with tests and honest limits.
3. **Choose your next step:** extend the starter towards that example, solve a different real annoyance or use the tools already in your project.

There is no package installation or app server for this route. Avoid building tools for their own sake.

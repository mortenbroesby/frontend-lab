# Experimental Projects bootstrap · One visible behaviour

**You need:** Node 24.x, npm, an editor and a browser for this optional starter. The shared playground uses React.

Follow the root [gallery setup](../../README.md#start-here) and create a [contribution branch](../../CONTRIBUTING.md) before editing.

Open the printed address followed by `/#/create`. Try the editable idea and colour, then follow the [demo generator guide](../../playground/src/demos/template/README.md) to create your own named folder. Open its printed route and edit its `Demo.tsx`, leaving the shared template available.

**Pick your first result:** one playable interaction, a quiz question, a drawing or a useful button. It does not need to resemble our example. Inputs reset on refresh; save code and record discoveries you want to keep.

**Success check:** open your demo from the gallery and try your interaction. Refresh and try again: the code change remains, while temporary input may reset. Ask a peer to try it using one sentence of instructions.

**Want a destination?** Open `/#/demo/art` separately for the generative postcard. Read the [worked example](examples.md) only when you want a reference or hint. No generator or export implementation is hidden in your starter.

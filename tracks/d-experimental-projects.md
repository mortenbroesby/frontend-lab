# Track D · Experimental Projects

A game, interactive data story, generative art, chapter quiz, utility or an idea nobody has suggested yet. Use your preferred technologies or the optional [playground](../playground/README.md).

## Start from a blank-enough space

Open `src/YourLab.tsx`. It contains only a small idea/colour interaction. Replace it with one visible behaviour. The examples stay available as references; you can hide them from the page while working. You do not need to edit the app shell to start.

If React is not the technology you want to explore, use your own setup and keep the journey prompts. The point is the experiment.

## Three possible destinations

| Idea | First visible result | Borrow if useful | Possible next branch |
| --- | --- | --- | --- |
| Generative postcard | Draw one shape using a rule you choose | SVG scene, seeded points, save-image behaviour | Add data, text or a new composition rule |
| Chapter quiz | Show one question and reveal an answer | Local signals to change a question in a second tab | Invent scoring or investigate a real multi-device design |
| Tiny browser game | One input changes a visible object | SVG controls and React state | Add a win condition, keyboard access or a different mechanic |

These are suggestions, not complete specifications. For the quiz, two local tabs are not multi-player networking across computers. For a game, a single playable interaction is enough to share.

## Assemble your own combination

Choose **an interest + a capability + a question**. For example: “generative art + Worker + can the controls remain responsive as I increase complexity?” Borrow a small part from [the browser journey](a-modern-web-capabilities.md), then choose the next step from what you observe.

A useful stopping point is one visible result and one thing learned. Record a sketch, demo or failed attempt in [findings](findings.md); polish and production readiness are optional.

# Track A · Modern Web Capabilities

Explore browser APIs, visual interaction, background computation or communication. Pick one capability and one question; you do not need to try them all.

1. **[Start small: bootstrap](bootstrap.md)** — a browser starting point in the shared app with one SVG circle and one control, ready for your experiment.
2. **[Experience the examples](examples.md)** — start with the D3 idea constellation; SVG art, Workers and local tab messages are additional possibilities.
3. **Choose your next step:** rebuild a small part of an example, change a rule, combine capabilities or use your own project.

The starter does not contain the finished solution. Use React for the interface while exploring native browser capabilities. Record one discovery in [findings](../findings.md).

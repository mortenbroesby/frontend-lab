# The Birthday Portrait

Explore the attic, read the letters and open the shuttered frame. Tap a marked object or use Tab and Enter. The hint changes as you discover clues. There is no time limit.

## Run

From the repository root after installing dependencies:

```sh
npm run dev --workspace @lab/demo-birthday-portrait
```

## Personalise the reveal

Replace `birthday-photo.jpg` with your JPEG. Edit the alt text, greeting and message in [birthday.ts](./birthday.ts). The frame fits portrait and landscape photos without cropping. The bundled seaside illustration is a placeholder. To share the personalised version, rebuild after changing the files.
